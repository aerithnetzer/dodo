# Dodo

Dodo is federated database system geared for libraries and cultural heritage
institutions. It (not yet fully) implements the ActivityPub protocol to
automate sharing between institutions.

## Motivation

Library catalog/search/etc. is becoming far too centralized. OCLC is suing
those who wish to scrape its data, Ex Libris is now part of a publicly traded
company, and many products are increasingly killed off or becoming very
monetized. Dodo is a product that attempts to help libraries ***OWN*** their
data, even if it is hosted on someone else's servers.

## Design Features

Dodo must remain easy to deploy. If it cannot be relatively easily deployed,
there is no point in making accessible software. The goal is that any
reasonably-skilled IT department can figure out how to deploy it,
in order of importance: a) securely, b) cheaply, and c) easily.

It should not use any idiosyncratic databases. Nor should it use ***ANY***
closed-source software anywhere in its ecosystem.
